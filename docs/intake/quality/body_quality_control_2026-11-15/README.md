# BODY control of `article_html/0.4.0` (frozen 2026-11-15, CPD-0041)

**For the operator's scientific acceptance** of the BODY selection of `article_html/0.4.0` against `0.3.0`, and of CORE on the
new BODY. Frozen before any human verdict: cases, questions and the machine's answers are fixed by digest in
[`manifest.json`](manifest.json); a second draw reproduced the manifest bit for bit.

## Files

| File | What | Open when |
|---|---|---|
| `manifest.json` | population, exclusions, seed, the 10 strata (sizes, populations, how drawn), the case list, the questions, the digests of the files below | any time |
| `verdicts_form.csv` | one row per case and question (135 rows, 45 cases): `FOREIGN`, `MISSING`, `CORE` | to answer |
| reading sheet `body_control_sheet_2026-11-15.html` | per case the address, the title and, numbered in page order, **every block that one of the two versions takes as BODY** -- which version keeps which is not shown. **Local only** (publisher text); regenerated by `scripts/study_body_quality.py draw` with the digest in the manifest | to answer |
| `KEY_machine_predictions_open_only_after_the_verdicts.json` | for each case the blocks each version keeps out (by number), the selection reasons, the body-quality state, the CORE decisions and reasons of both versions, random or targeted | **only after every answer is entered** |

## How to answer

For each case: the numbers of the blocks that are **not** text of this article (`FOREIGN`; `0` if all are), whether article
text is missing compared with the page (`MISSING`), and the CORE judgement (`CORE`). Then

```
python scripts/study_body_quality.py merge --out-dir docs/intake/quality/body_quality_control_2026-11-15 \
    --verdicts <filled form> --out <result.json>
```

`merge` refuses a key that is not the frozen one and counts, for each version and apart for the random (16) and the targeted
(29) component: blocks kept out that are foreign (correct removals), blocks kept out that are article text (**false
deletions**), blocks kept in that are foreign (**residual contamination**); and CORE agreement.

## What it can and cannot say

- A holdout within the known population, not fresh data: the rules were developed on aggregate measurements of all 4,759
  pages and on listings of removed blocks; the control excludes every page opened one by one during this run, the phase-3
  blind control and the 2026-11-15 review.
- The random component (16 of 4,504 eligible pages, systematic, equal probability) speaks to the population only coarsely; the
  targeted strata (large removals, inclusions, templates, modules, CORE changes, residual and unchanged-clean pages, not-article)
  look for errors and estimate no precision.
- Text that neither version shows as BODY can be reported only through `MISSING`.
